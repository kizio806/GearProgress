# Installation Guide

1. Download the distribution JAR corresponding to your server platform:
   - For **Paper**, **Purpur**, or **Folia**: `GearProgress-<version>-paper.jar`
   - For **Spigot** or **CraftBukkit**: `GearProgress-<version>-spigot.jar`
2. Place the JAR file into your server's `plugins/` directory.
3. Ensure your server is running Minecraft 1.21.x and Java 21+.
4. Start your server. GearProgress will automatically generate default configuration files in `plugins/GearProgress/`.
5. Customize `config.yml`, `equipment.yml`, `timers.yml`, and `storage.yml` as desired.
6. Run `/gearprogress reload` to apply changes.
