# GearProgress 1.0.0 — Minecraft 1.21.x

**Initial release of GearProgress** — a progressive, permission- and advancement-based equipment gating engine for Paper, Purpur, Folia, and Spigot servers running Minecraft 1.21.x.

---

## 🚀 Highlights

- **Unified Global Versioning Standard**: Established authoritative Semantic Versioning with Minecraft compatibility build metadata (`1.0.0+mc1.21.x`).
- **Standardized Multi-Platform Distribution Artifacts**: Dual distribution packaging producing `gearprogress-1.0.0-mc1.21.x-paper-purpur-folia.jar` and `gearprogress-1.0.0-mc1.21.x-spigot-bukkit.jar`.
- **Pure Hexagonal Architecture**: Domain logic completely decoupled from server APIs (`gearprogress-core`), orchestration in `gearprogress-application`, and runtime adapters in `:platforms:*`.
- **Folia Regional Threading**: Native compatibility with Folia's `RegionTaskScheduler` alongside standard Paper and Spigot runtimes.
